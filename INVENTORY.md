## Directory structure

```

│   ├── legacy/               # Old metrics codebase, pre-dates this project — do not touch

│   ├── ablation_study.py     # Optimization ablation (baseline → precomputed → optimized existence → dynamic+)
│   ├── compare_confusion_matrix.py  # Confusion matrix comparison (--backend numpy/torch)
│   ├── compare_existence_reward.py  # Existence reward analysis
│   ├── compare_rank_vus.py   # Detector ranking comparison between metrics
│   ├── compare_runtime.py    # Runtime comparison utility
│   ├── compute_metric.py     # Bulk metric computation over a dataset (produces experiment CSVs)
│   ├── demo_vus.py           # Streamlit interactive demo
│   ├── evaluate_ffvus.py     # End-to-end FF-VUS evaluation across random time series
│   ├── existence_skip_analysis.py   # Analysis of existence algorithm skip behavior
│   ├── generate_synthetic.py # Synthetic time series generator
│   ├── precompute_existence.py      # Precompute existence values (run before compute_metric)
│   ├── precompute_rankings.py       # Precompute detector rankings
│   ├── verify_cumulative.py  # Regression test for cumulative VUS computation
│   └── vus_visualizer.py     # Paper figure generation (all plots, --plot <name>)
├── scripts/                  # SLURM shell scripts for each experiment
│   ├── create_shell_scripts.py      # Script generator (reads templates.py)
│   ├── templates.py          # Config templates for each experiment type
│   └── <experiment_name>/    # One subdirectory per experiment (conduct_*.sh + per-job *.sh)
├── experiments/              # Experiment outputs (results, info, logs, figures)
├── data/                     # Empty — data lives in tsbadparser repo (data/raw, data/scores)
├── notes/
│   └── notes.json            # Manual annotations on specific time series (interesting cases)
├── references/               # Paper submissions (kdd2026_submission/, vldb26_submission/)
├── environment.yml           # Conda environment spec
└── requirements.txt          # Pip requirements
```

## Experiments

All experiments labelled **"tsb"** ran against **TSB-UAD** (via `src/utils/dataloader.py` → `data/raw`, `data/scores`).
Synthetic experiments ran on generated data in `data/synthetic/` (syn_0 … syn_9).

### allmetrics_defparams_tsb
**What:** Full benchmark of all metrics at default parameters on TSB-UAD (1887 time series).
**Metrics:** FF-VUS, FF-VUS-GPU, VUS, AUC, RANGE-AUC, AFFILIATION, RF
**Params:** buffer=128, step=1, slopes=precomputed, existence=optimized, confusion=dynamic_plus, global_mask=True
**Dataset:** TSB-UAD (full, all sub-datasets)
**Script:** `src/compute_metric.py --dataset tsb --metric <metric> --experiment allmetrics_defparams_tsb`
**Re-run on TSB-AD:** YES — this is the main comparison table

### allmetrics_defparams_syn
**What:** Same full metric benchmark on synthetic datasets (syn_0 … syn_9, 10 sets × 48 time series each).
**Metrics:** FF-VUS, FF-VUS-GPU, VUS, AUC, RANGE-AUC, AFFILIATION, RF
**Params:** same as tsb variant
**Dataset:** synthetic (generated by `generate_synthetic.py`)
**Script:** `src/compute_metric.py --dataset syn_<N> --metric <metric> --experiment allmetrics_defparams_syn`
**Re-run on TSB-AD:** NO — synthetic data is self-contained; regenerate if needed

### vus_buffer_comparison_tsb
**What:** Buffer size ablation — FF-VUS at buffer ∈ {0, 2, 4, 8, 16, 32, 64, 128, 256, 512} on TSB-UAD (1887 time series, step=1, dynamic_plus).
**Dataset:** TSB-UAD
**Re-run on TSB-AD:** YES — supports buffer sensitivity claim

### vus_step_comparison_tsb
**What:** Step size ablation — FF-VUS at buffer=512, step ∈ {1, 2, 4, 8, 16, 32, 64, 128, 256, 512} on TSB-UAD (1887 time series, dynamic_plus).
**Dataset:** TSB-UAD
**Re-run on TSB-AD:** YES — supports step sensitivity claim

### vus_ffvus_auc_0_tsb
**What:** Equivalence check — VUS, FF-VUS, FF-VUS-GPU, AUC all run at buffer=0 on TSB-UAD (1887 time series). Shows FF-VUS degenerates to AUC when buffer=0.
**Dataset:** TSB-UAD
**Re-run on TSB-AD:** YES — supports AUC-equivalence claim

### vus_ffvus_auc_0_syn
**What:** Same equivalence check on synthetic data. Results directory is **empty** — not yet run.
**Dataset:** synthetic
**Re-run on TSB-AD:** NO — run on synthetic first, re-run only if synthetic data is regenerated

### compare_rank
**What:** Per-dataset ranking comparison (VUS vs FF-VUS) across all 20 TSB-UAD sub-datasets (Daphnet, Dodgers, ECG, Genesis, GHL, IOPS, KDD21, MGAB, MITDB, NAB, NASA-MSL, NASA-SMAP, Occupancy, OPPORTUNITY, SensorScope, SMD, SVDB, YAHOO).
**Script:** `src/compare_rank_vus.py --dataset <name> --metric vus`
**Dataset:** TSB-UAD (per sub-dataset)
**Re-run on TSB-AD:** YES — ranking stability across datasets is a paper argument

### compare_train_metrics
**What:** Training-time metric comparison — AUC, VUS, FF-VUS, FF-VUS-GPU used as training objectives for MLP × 10 epochs on KDD21 (TSB-UAD, 1400 time series). Measures loss values and timing.
**Dataset:** TSB-UAD / KDD21
**Re-run on TSB-AD:** YES — re-run on TSB-AD equivalent of KDD21 (or closest match)

### ablation_study
**What:** Step-by-step optimization ablation: baseline (no optimizations) → + precomputed slopes → + optimized existence → + dynamic+ confusion matrix. Measures time and metric value.
**Dataset:** TSB-UAD / ECG, n=10, run locally on NVIDIA RTX PRO 1000 Blackwell GPU machine
**Re-run on TSB-AD:** PARTIAL — timing results are machine-dependent, not dataset-dependent. If ECG is in TSB-AD, rerun for consistency; otherwise timing claim still stands.

### softed_tsb
**What:** SOFTED (softened metrics, R implementation) on TSB-UAD SVDB dataset. Single result file.
**Dataset:** TSB-UAD / SVDB
**Re-run on TSB-AD:** YES — if SOFTED is kept as a baseline in the paper

### existence_comparison
**What:** Correctness and speedup comparison of trivial vs. optimized existence algorithm on TSB-UAD (128 slopes). Shows ~1000× speedup, zero difference in output.
**Dataset:** TSB-UAD (subset)
**Re-run on TSB-AD:** NO — this is a correctness/timing test, not a benchmark result for the paper

### existence_skip_analysis
**What:** Analysis of how often the existence algorithm can skip computation. One output file (`skip_stats.csv`).
**Dataset:** unclear (single file, small run)
**Re-run on TSB-AD:** PROBABLY — if cited in the paper; small run

### preliminary
**What:** Early run before default params were finalized. FF-VUS-PR, VUS-PR, AUC-PR, RANGE-AUC-PR, AFFILIATION, RF on TSB-UAD (1884 time series, buffer=100, step=1, existence=optimized, confusion=dynamic). **Superseded by allmetrics_defparams_tsb.**
**Dataset:** TSB-UAD
**Re-run on TSB-AD:** NO — superseded; allmetrics_defparams_tsb replaces this

### cummulative_vus
**What:** Cumulative VUS visualizations on YAHOO (TSB-UAD). Five PNG figures showing extreme/good/nonsense cases. No quantitative results — paper figures only.
**Dataset:** TSB-UAD / YAHOO
**Re-run on TSB-AD:** NO — figures can be regenerated from any dataset; update source series if needed

### vus_inv_yahoo
**What:** Early exploration — VUS-PR-inv and VUS-ROC-inv (inverted weight slope) on YAHOO (TSB-UAD). Single results.csv.
**Dataset:** TSB-UAD / YAHOO
**Re-run on TSB-AD:** NO — this idea was abandoned (see src/archive/)

### vus_v2_yahoo
**What:** Early exploration — VUS-PR-uniform and VUS-ROC-uniform on YAHOO (TSB-UAD). Single results.csv.
**Dataset:** TSB-UAD / YAHOO
**Re-run on TSB-AD:** NO — abandoned idea

### synthetic_data_generation
**What:** Generated synthetic time series (syn_0 … syn_9). The results directory is empty — outputs (the synthetic data files) likely live in `data/synthetic/`.
**Dataset:** N/A (generates data)
**Re-run on TSB-AD:** NO

### figures
**What:** 38 PDF figures produced by `vus_visualizer.py`. These are paper-ready plots derived from the above experiments.
**Re-run on TSB-AD:** AFTER experiments — regenerate once allmetrics_defparams_tsb and buffer/step comparison experiments are re-run on TSB-AD
